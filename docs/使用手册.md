# 使用手册

> 面向日常使用。构建与接口细节见 [架构说明](架构说明.md)。

## 1. 安装

**方式 A：下载现成 APK（推荐）**

到本仓库的 [Releases](../../releases) 页面下载最新的 `TaskMate-x.y.apk`，传到手机安装。
小米会提示「未知来源应用」，允许一次即可。

**方式 B：自己构建**

```bash
bash scripts/setup-toolchain.sh   # 首次：装 JDK 17 + Android SDK + Gradle（约 1.2 GB）
bash scripts/build-apk.sh         # 产物：dist/TaskMate-x.y.apk
```

**方式 C：局域网直接下**

```bash
bash scripts/serve-apk.sh         # 打印出手机可访问的地址
```

首次启动会让允许通知——**不开也能用**，只是不会提醒。

## 2. 小米必做的三件事

MIUI / HyperOS 对后台很激进，不设置的话提醒可能延迟甚至不响：

1. 设置 → 应用设置 → 应用管理 → 任务助理 → **自启动**：打开
2. 同一页 → **省电策略** → 选「**无限制**」
3. App 内「设置 → 精确提醒」：显示「未允许」时点一下，跳到系统开关打开

App 设置页还能一键「发送测试通知」和「60 秒后测试提醒」，用来确认整条链路通不通。

## 3. 三个视图

**今天**

- 顶部渐变卡：完成度环、待处理 / 已完成 / 逾期
- 逾期（红）永远排最前
- 「待安排」：没定日期的任务都在这里，点一下就能补时间
- 底部「添加任务」在拇指可及的位置

**本周**

- 周一到周日日期条，有任务的日子下面有小圆点
- ‹ › 切上一周 / 下一周，切周后自动选中同一天
- 不是本周时出现「回到本周」

**全部**

- 自动分区：已逾期 / 今天 / 本周稍后 / 以后 / 没有日期 / 已完成
- 顶部搜索；右上角漏斗切「待办 / 已完成 / 全部」

**手势**：点圆圈完成 · 点行打开详情 · 左滑「明天」 · 右滑「完成 / 删除」 · 长按改优先级

## 4. 快速添加

点任意「+」打开。默认已经填好**今天 + 下个 5 分钟整点**，提醒默认开启。

- **日期 / 时间**两行始终可见，点任一行即可修改；内置时间选择器带快捷项（现在 / 09:00 / 12:00 / 18:00 / 20:00）
- 选到已过去的时刻会自动顺延到明天
- **重复**：不重复 / 每天 / 工作日 / 每周 / 每月。勾完成的瞬间自动生成下一次，提醒提前量一起带过去
- **优先级**：不急 / 普通 / 重要（重要会在标题加粗 + 橙色标记）
- **无日期**：也可以，任务会进「待安排」

## 5. 提醒

- 系统精确闹钟（`setExactAndAllowWhileIdle`）+ 通知渠道，App 被杀、重启后都会响
- 通知上直接点「完成」或「10 分钟后」，不用打开 App
- 点通知正文直接打开这条任务
- 改时间 / 完成 / 删除会自动取消或重排

## 6. 桌面小组件

长按桌面 → 小组件 → 任务助理 → 拖到主屏（4×2）。显示今天还剩几件 + 前三条任务，点一下进 App。

## 7. 电脑端控制台

```bash
cd server
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt   # 首次
.venv/bin/python main.py
```

终端会打印 `API Key` 和局域网地址。浏览器打开 `http://127.0.0.1:8788/?key=<API Key>` 进入控制台。

手机端：**设置 → 电脑端同步**，填 `http://<电脑局域网IP>:8788` 和同一个 API Key，打开开关。

在控制台里可以：看全部任务与统计、改标题和时间、勾完成、删除、回车新增。

**同步规则**

- 每条任务带 `updated_at`，按「谁后改谁生效」合并（服务端为准）
- 删除是软删除墓碑，不会因为另一台设备还有旧数据就复活
- 手机本地优先：没网、电脑没开照样能用，联网后自动合并
- 手机改动 0.9 秒内推送；电脑改动在手机回到前台时拉取

**想让它一直开着**

```bash
bash scripts/install-autostart.sh          # 开机自启（launchd），崩溃自动拉起
bash scripts/install-autostart.sh --remove # 取消
```

## 8. 备份与迁移

设置 → 数据 → **导出备份**，会把全部任务导出成 JSON 存到「文件」。
换手机时把 JSON 留好即可（当前版本导入还在路线图上）。

## 9. 常见问题

**提醒不响**
自启动、省电策略、通知权限、精确提醒四项都检查；再用「60 秒后测试提醒」验证。

**同步失败**
手机和电脑是否同一 Wi-Fi；Mac 防火墙是否放行 8788；地址是否带 `http://` 和端口；API Key 是否一致。

**控制台打不开**
`main.py` 是否在跑；端口被占用可改 `server/.env` 里的 `PORT`。

**装不上 / 解析包错误**
重新传一次 APK；确认 Android 8.0 以上。

**换手机后数据没了**
数据在手机本地 + 电脑 SQLite。装好新机后连上同一个服务端，会从电脑拉回全部任务。
